# MVP 0.1

## Goal

Validate whether users understand and enjoy semantic slider-based visual discovery.

## Category

Fashion → Pants.

This category was selected because shape, volume, structure and style vary visibly and unusual examples are easy to compare.

## Required functionality

- grid of references;
- 5–7 semantic sliders;
- immediate client-side ranking;
- score/match indicator for debugging the behavior;
- Explore this;
- Save / unsave;
- LocalStorage moodboard;
- original source link;
- responsive mobile layout.

## Seed volume

The checked-in dataset is intentionally tiny and is only for UI development.

For meaningful user testing target:

- 100 items: interaction smoke test;
- 300–500 items: first category validation;
- 1,000–3,000 items: enough visual density for slider discovery to become interesting.

## What to measure later

- slider interactions per session;
- percentage of sessions using Explore this;
- saves per session;
- source click-through rate;
- time to first save;
- number of slider changes before a source click;
- repeated movement around the same visual neighborhood.

## Not part of MVP 0.1

No accounts, payments, creator onboarding, generation, web-scale crawling or production dispatch.
