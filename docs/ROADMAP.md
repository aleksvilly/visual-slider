- collect 300–1,000 Pants references;
- define source normalization format;
- batch AI scoring;
- import script;
- deduplicate near-identical references;
- analytics events for slider/save/source interactions;

## Phase 2 — prove generic engine

Add a category that is not fashion, e.g. Cakes or Furniture.

Success condition: same ranking/UI architecture works with a different semantic schema.

## Phase 3 — ingestion platform

- database;
- source adapters;
- analysis jobs;
- embeddings;
- admin review UI;

## Phase 4 — creator/partner layer

- creator submissions;
- claim existing indexed work;
- creator profile/source attribution;
- licensed download/customization actions;
- partner buy links.

## Phase 5 — maker workflow

Potential actions after discovery:

- export moodboard/spec summary;
- request a quote;
- send to atelier/print shop/bakery/maker;
- attach dimensions/budget/preferences.

Production-ready CAD/tech packs are a separate later product problem and are not required for Visual Slider to be useful.
