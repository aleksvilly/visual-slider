# Product definition

## One sentence

Visual Slider helps people discover visual references by moving human-friendly semantic sliders instead of knowing the right search vocabulary.

## Problem

Visual search is often vocabulary-gated. A user can recognize that they want something “more square”, “less normal”, “more business”, “softer”, “more minimal” or “weirder”, but may not know the design/fashion/interior terminology needed to search for it.

Traditional filters are also too categorical: they hide results once a condition fails.

## Solution

Index existing work, analyze it once, then expose selected continuous attributes as sliders. Slider movement updates relevance rather than enforcing binary inclusion/exclusion.

The experience should feel almost generative even though every result already exists.

## Core interaction

1. Browse a category.
2. Move one semantic slider.
3. Observe the grid reorder immediately.
4. Find an interesting item.
5. Click **Explore this**.
6. Sliders jump to that item's approximate position in visual space.
7. Nudge one property: “like this, but more minimal.”
8. Save results into a moodboard or open the source.

## Why existing content first

- faster MVP;
- factual, real-world references;
- users can often buy the existing item immediately;
- creators/stores can receive traffic;
- avoids depending on generated imagery quality;
- establishes a dataset that can later support optional generation.

## Long-term actions

An indexed result may eventually support different actions:

- VIEW SOURCE
- BUY ORIGINAL
- SAVE
- ADD TO MOODBOARD
- LICENSE FROM CREATOR
- CUSTOMIZE WITH CREATOR
- REQUEST SOMETHING LIKE THIS
- SEND TO MAKER

These actions are downstream of discovery; they should not complicate the first validation build.
